# Images d’accueil ADEIO

Les fonds provisoires sont les fichiers SVG locaux `hero-bg.svg`, `about-bg.svg` et `cta-bg.svg`.

Pour les remplacer par des photos sans modifier le code, déposez un fichier JPG ou WebP avec l’un de ces noms exacts :

- `hero-bg.jpg` ou `hero-bg.webp` ;
- `about-bg.jpg` ou `about-bg.webp` ;
- `cta-bg.jpg` ou `cta-bg.webp`.

Une photo locale est prioritaire sur le SVG de secours correspondant et reste servie par `next/image`. Préférez des photos horizontales (environ 1600 × 900 px), compressées et sans texte incrusté. Vérifiez les autorisations de publication avant d’ajouter des personnes reconnaissables.
